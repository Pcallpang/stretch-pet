# 캐릭터 변경

펫을 오른쪽 클릭하고 **캐릭터 변경**에서 미요, 미요X (사춘기), 더드미요, 갓미요를 선택합니다. 현재 캐릭터에는 선택 표시가 나타납니다. 선택은 기존 설정 파일에 저장되며 다음 실행에도 복원됩니다. 기존 사용자의 기본 캐릭터는 미요X입니다.

캐릭터를 바꿔도 위치, 고정 여부, 집중 시간, 현재 스트레칭 단계와 남은 시간은 유지됩니다.

## 에셋

`output/stretch-assets-v1`의 네 시트를 `node scripts/import-character-sheets.mjs`로 처리합니다. 결과는 `assets/characters/<캐릭터>/`의 투명 PNG 64개입니다. 원본은 보존합니다. 시트별 행 경계를 조정해 잘림을 방지하며, 외곽에 연결된 체크무늬 배경과 작은 잔여 점을 제거합니다. 생성 이미지 특성상 발광 가장자리에 원본의 밝은 테두리가 일부 남을 수 있습니다.

앱은 캐릭터별 대기 2컷, 걷기 4컷, 의자 스트레칭 8컷을 사용합니다. 추가 서서 스트레칭 2컷도 `standing` 폴더에 보관됩니다.

## 검증

`npm test`와 `npm run test:smoke`로 설정 검증, 메뉴 선택 저장, 이미지 로드, 렌더러 재로드 시 복원, 스트레칭 중 캐릭터 변경 및 기존 루틴을 검사합니다.
