# Desktop Stretch Pet (데스크톱 스트레칭 도우미) 설계 문서

## 1. 개요

노트북/PC 화면 위를 자유롭게 돌아다니며, 정해진 주기마다(기본 50분 집중 / 5분 스트레칭) 의자
스트레칭 8동작을 시연하고 유도하는 데스크톱 펫 프로그램. 캐릭터는 시크/츤데레 콘셉트의 검은
유령 '미요-X'.

## 2. 기술 스택

- **Framework**: Electron
- **언어**: TypeScript
- **렌더러**: 순수 HTML/CSS/DOM (React 미사용)
- **설정 저장**: `electron-store`

### 채택 이유 / 기각한 대안

| 후보 | 판단 |
|---|---|
| Electron + TS + 순수 DOM (채택) | 화면 요소가 캐릭터·말풍선·설정창 정도로 단순해 React 상태관리 오버헤드가 불필요. 디버깅이 쉬움 |
| Tauri | 설치 용량은 작지만 `setIgnoreMouseEvents` 등 이번 프로젝트가 요구하는 Electron 전용 API를 다시 구현해야 해 개발 속도가 느려짐 |
| Electron + React | 이 규모의 화면에는 과함 |

## 3. 프로세스 구조

Electron은 메인 프로세스와 렌더러 프로세스로 나뉜다.

- **메인 프로세스** (`src/main.ts`): 투명 창 생성, 클릭 스루 on/off, 트레이 아이콘, 타이머(집중/
  스트레칭 간격) 관리, 설정 파일 저장/불러오기, 시작 프로그램 등록
- **렌더러 프로세스** (`src/renderer/*`): 캐릭터 그리기, 걷기 애니메이션, 말풍선 표시, 스트레칭
  진행 UI
- **preload** (`src/preload.ts`): 메인↔렌더러 간 안전한 IPC(프로세스 간 메시지 전달) 통로. 예:
  메인이 "50분 다 됐다"를 보내면 렌더러가 캐릭터를 화면 중앙으로 이동시킴

## 4. 윈도우 구성

- 화면 전체를 덮는 투명 오버레이 창 (`transparent: true`, `frame: false`, `alwaysOnTop: true`)
- 평상시 `setIgnoreMouseEvents(true, { forward: true })`로 클릭 스루 처리 — 캐릭터 영역 밖 클릭은
  뒤쪽 프로그램으로 통과
- 캐릭터 호버/드래그/알림 인터랙션 시에만 마우스 이벤트 활성화

## 5. 상태 머신 (FSM)

5가지 상태:

1. **IDLE** — 화면 하단에 정지, 가끔 눈 깜빡임
2. **WALK** — 좌우로 천천히 배회, 화면 끝에 닿으면 방향 반전(`scaleX(-1)`)
3. **ALERT** — 타이머 종료 시 걷기를 멈추고 화면 중앙 쪽으로 이동 + 말풍선 등장
4. **STRETCH** — 의자 스트레칭 8동작을 순서대로 재생 (동작당 10~15초 카운트다운 + 애니메이션
   루프), 동작명+안내문구를 말풍선으로 노출
5. **COOLDOWN** — 완료/스킵 후 일정 시간 재알림 억제, 종료되면 IDLE/WALK로 복귀

```
IDLE ⇄ WALK --(타이머 종료)--> ALERT --(사용자 시작 클릭)--> STRETCH
  --(8동작 완료 또는 스킵)--> COOLDOWN --(쿨다운 종료)--> IDLE/WALK
```

FSM 전환 로직은 상태와 이벤트만 입력받는 순수 함수(`fsm.ts`)로 구현해 유닛 테스트가 가능하게
한다.

## 6. 스프라이트 / 애니메이션

- 최초 첨부된 참고 이미지(`미요X 데스크톱펫.png`)는 프레임 크기·간격이 불균일한 컨셉 시트라
  격자 좌표 매핑 대신 **개별 PNG 낱장으로 슬라이싱**해 사용한다.
- 폴더 구조: `assets/idle/1.png ~2.png`, `assets/walk/1.png~5.png`,
  `assets/stretch/<동작명>_N.png` (동일 포즈 중복 프레임은 정리)
- `spriteAnimator.ts`는 "이 폴더의 프레임들을 몇 fps로 재생할지"만 알면 되도록 상태 코드와
  분리해서 구현 — 나중에 그림 자산이 바뀌어도 이 모듈은 안 건드림

## 7. 캐릭터 성격 / 대사

시크/츤데레 콘셉트 '미요-X'. 대사는 `dialogues.json`에 상태별(시작/동작 안내/완료)로 모아두고,
같은 상태에서도 매번 랜덤으로 하나를 뽑아 노출한다. 예시:

- 시작: "알빠임? 그래도 척추는 펴라.", "거북목 상태로 일하면 퇴근도 늦어진다."
- 동작 안내: "목 옆으로 당겨, 10초만 버텨.", "어깨 돌려라. 굳은 거 다 보인다."
- 완료: "수고했다. 다시 일해라."

## 8. 설정 / 트레이

- `electron-store`로 사용자 설정(집중 시간, 스트레칭 시간, 소리 on/off, 시작 프로그램 등록
  여부)을 로컬 JSON으로 저장 — 재실행해도 유지
- 트레이 메뉴: 간격 설정(기본 50분/5분, 프리셋 + 직접 입력), 소리 On/Off(1차 버전은 비활성 —
  UI만 만들어두고 나중에 사운드 파일 연결), 시작 프로그램 등록, 프로그램 종료
- 1차 버전은 사운드 파일 없이 애니메이션+말풍선만으로 알림

## 9. 폴더 구조

```
S04-스트레칭펫(StretchPet)/
  package.json
  tsconfig.json
  src/
    main.ts              # 메인 프로세스: 창 생성, 트레이, 타이머, 설정
    preload.ts           # 메인↔렌더러 IPC 통로
    renderer/
      index.html
      renderer.ts         # 캐릭터 동작 제어
      spriteAnimator.ts   # 프레임 재생
      fsm.ts               # 상태 전환 로직 (순수 함수)
      dialogues.json       # 미요-X 대사 모음
      style.css
  assets/
    idle/  walk/  stretch/   # 낱장 PNG
  CLAUDE.md
```

## 10. 에러 처리

창 생성 실패, 트레이 아이콘 로드 실패, 설정 파일 손상 시 기본값으로 복구하고 "설정을 불러오지
못해 기본값으로 시작했다" 정도의 조용한 알림만 노출한다.

## 11. 테스트

- FSM 전환 로직은 순수 함수라 유닛 테스트로 검증
- 실제 창/트레이/클릭 스루 동작은 수동으로 앱을 띄워 눈으로 확인
